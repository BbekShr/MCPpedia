# Learnings

Durable, proven lessons so each run is smarter than the last. The CEO is the **sole writer**;
agents read them only because the CEO prepends them to briefs.

- `_shared.md` applies to every agent; `<agent-name>.md` to one agent. Create an agent's file the
  first time it earns a lesson.
- Only `## Active` enters briefs: short imperatives, ≤ ~30 lines per file, each citing a
  PR/commit/file. `## Archive` is unbounded (war stories, stale-but-true items) and never enters a brief.
- Demote still-true lessons to Archive; never delete one to hit a line count. Delete only when falsified.
- A lesson is a reusable gotcha, fix pattern or tooling trap, not a run log.
