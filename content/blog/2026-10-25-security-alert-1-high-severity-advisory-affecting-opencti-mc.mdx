## CVE-2026-114055 — HIGH

**vLLM : DoS via unvalidated mm_processor_kwargs in multimodal image processors (Isaac, InternVL, H2OVL, etc.)**

Affects [Opencti_mcp_server](/s/opencti-mcp-server).

<ServerCardMini slug="opencti-mcp-server" name="Opencti_mcp_server" />

API clients can supply arbitrary `mm_processor_kwargs` per request. vLLM forwards these values through the multimodal rendering and processing pipeline to Hugging Face and custom image/video processor constructors and calls. Resource-sensitive values such as image size, patch size, patch count, crop count, or frame count can therefore be controlled by a remote client. For processors that upscale inputs, a single request can force an allocation large enough to terminate the API serve
