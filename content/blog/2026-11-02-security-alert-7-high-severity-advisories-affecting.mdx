## CVE-2026-119203 — HIGH

**pypdf has possible infinite loop when hitting EOF in standard xref table during trailer search**

Affects [io.github.pipeworx-io/asrs-reports](/s/io-github-pipeworx-io-asrs-reports).

<ServerCardMini slug="io-github-pipeworx-io-asrs-reports" name="io.github.pipeworx-io/asrs-reports" />

An attacker who uses this vulnerability can craft a PDF which leads to an infinite loop. This requires opening an incomplete file without a `trailer`. Patches This has been fixed in [pypdf==6.21.4](https://github.com/py-pdf/pypdf/releases/tag/6.21.4). Workarounds If you cannot upgrade yet, consider applying the changes from PR [#4289](https://github.com/py-pdf/pypdf/pull/4289).

*Published 2026-10-30.*
