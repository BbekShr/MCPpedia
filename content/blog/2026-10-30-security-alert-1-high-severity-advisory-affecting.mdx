## CVE-2026-61438 — HIGH

**PraisonAI vulnerable to Remote Code Execution via Broken AST Sandbox**

Affects [io.github.MervinPraison/praisonai](/s/io-github-mervinpraison-praisonai-mervinpraison).

<ServerCardMini slug="io-github-mervinpraison-praisonai-mervinpraison" name="io.github.MervinPraison/praisonai" />

JobWorkflowExecutor._exec_inline_python() is designed to safely execute inline Python expressions from YAML workflow script: steps using AST validation. The function claims to block dangerous operations by (a) checking all AST nodes against an allowlist, and (b) providing a __builtins__ whitelist that omits __import__, exec, eval, and open. The sandbox is broken. The module import allowlist (allowed_modules) explicitly includes 'os', and the AST allowlist permits ast.Import, ast.Imp
